# The OOP Toolkit

!!! abstract "What You Will Learn"
    By the end of this guide you will be able to:

    - Recognize the handful of problems that show up in almost every game's code
    - Pick the right tool for each: composition, interfaces, events, state, strategy, command, or generics
    - Explain *why* each tool helps, in terms of what changes and what doesn't have to
    - Spot the habits that make code harder to change (type checks, singletons, fat MonoBehaviours)
    - Decide when a problem doesn't need any of this at all

**Difficulty:** Intermediate · **Time:** ~45 minutes
