# Design

These pages embed the team's working documents straight from Google Drive, so they always show the latest version. Edit them in Google Drive, not here.

| Document | Owner | What's in it |
|---|---|---|
| [Game Design Document](game-design-doc.md) | Design team | The source of truth for mechanics: player moveset, equipment, boss behavior, progression, controls, and UI. |
| [Art Document](art-document.md) | Art team | Art direction and asset planning. |
| [Audio Tracker](audio-tracker.md) | Audio team | The spreadsheet tracking music and sound effects. |

The story team's document lives under [Story](../story/index.md).

!!! tip "Designers: changing numbers in the game"
    The [Tuning Guide](../codebase/tuning-guide.md) lists every value you can change in Unity (player speed, boss health, attack timing, gun recoil) and what it's set to now.

!!! tip "Programmers: read the GDD with the code docs open"
    The [codebase docs](../codebase/index.md) list where Milestone 1's code differs from the GDD, in the **Differs from the GDD** section at the end of each system page. Those notes are a good place to find work that's ready to pick up.
